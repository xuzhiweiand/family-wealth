## 一、项目概述

### 1.1 项目背景

家庭是社会经济活动的核心单元，但绝大多数家庭对自己的**资产全貌**缺乏清晰认知：股票账户里有多少钱、银行存款有多少、理财收益怎么样、还有多少负债——这些信息散落在不同 App 中，难以形成统一视图。

本项目专为家庭打造一款**纯资产管理**工具：不需要逐笔记账，只需记录资产状态，自动呈现资产变化全景。

### 1.2 项目愿景

让每个家庭 **一眼看清自己的家底，洞察资产变化趋势**。

### 1.3 核心价值主张

- **全景视图**：所有资产在一个屏幕内一网打尽。
- **轻量录入**：每周 / 月花 5 分钟更新资产状态，无需每日记账。
- **变化洞察**：自动生成趋势图、占比饼图、收益率分析。
- **隐私至上**：端到端加密，财务数据真正属于家庭。

### 1.4 业务目标（12 个月）

- 注册家庭：30,000+
- 付费转化率：8%（家庭版订阅 ¥98 / 年）
- 7 日留存 > 50%（轻量使用，门槛低）
- App Store 评分 ≥ 4.6

## 二、目标用户

### 2.1 用户画像

| 用户类型          | 占比  | 核心需求       | 典型场景           |
| ------------- | --- | ---------- | -------------- |
| **多账户家庭**     | 55% | 看清家底、追踪变化  | 月初 / 季末更新资产、复盘 |
| **投资理财家庭**    | 20% | 追踪收益率、资产配置 | 每日看股票走势、月度评估   |
| **退休 / 长辈家庭** | 15% | 退休金 / 资产保值 | 查看总资产、保守资产占比   |
| **多代同堂家庭**    | 10% | 家庭共财、共同规划  | 父母 / 子女共建家庭账本  |

### 2.2 核心痛点

1. **信息分散**：银行 App、券商 App、支付宝、信用卡——钱在多处，无法形成统一视图。
2. **变化不清**：不知道今年总资产涨了多少，也不知道各类资产的增减情况。
3. **配置盲目**：不知道自己的资产配置是否合理，股票占比是否过高。
4. **决策困难**：家庭重大财务决策（买房、投资）缺乏数据支撑。
5. **手动汇总**：每次都要打开多个 App 抄数据，效率极低。

### 2.3 用户故事示例

> 作为一个多账户家庭，**我想要** 在一个屏幕看到所有银行、券商、理财账户的总资产，**以便** 清晰了解家底。
>
> 作为一个投资家庭，**我想要** 自动追踪股票账户的市值变化，**以便** 评估投资表现。
>
> 作为退休父母，**我想要** 看到自己"退休金 + 房产 + 理财"的整体资产分布，**以便** 安心规划退休生活。

## 四、详细功能说明（精选）

### 4.1 资产管理（核心）

**用户故事**：作为多账户家庭，我想要把家里所有的资产录入 App，以便一眼看清家底。

**支持的资产类型**：

| 资产类型     | 示例            | 数据字段              |
| -------- | ------------- | ----------------- |
| **现金**   | 钱包现金          | 金额、币种、备注          |
| **银行存款** | 招行活期 / 工商定期   | 账户名、银行、金额、利率、到期日  |
| **股票**   | 国泰君安账户        | 账户、持仓、市值、盈亏       |
| **基金**   | 余额宝 / 主动基金    | 名称、份额、市值、近 1 月收益率 |
| **理财**   | 银行理财          | 产品名、本金、收益、到期日     |
| **房产**   | 自住 / 投资房      | 地址、估值、贷款余额、产权人    |
| **车辆**   | 自家用车          | 车型、估值、贷款余额        |
| **数字货币** | BTC / ETH     | 持仓数量、市值（按实时汇率）    |
| **贵金属**  | 黄金 / 白银       | 数量、市值             |
| **债权**   | 借出款项          | 借款人、金额、到期日、利率     |
| **债务**   | 房贷 / 车贷 / 信用卡 | 总额、已还、剩余、月供       |

**录入方式**：

- 手动输入（P0）：金额 + 类型 + 名称，MVP 基础
- 截图 OCR（P1）：拍银行 App 截图，自动识别（详见 3.2 P1 功能列表）
- CSV / Excel 导入（P1）：批量导入历史数据
- API 接入（P1）：部分券商支持（未来）

**验收标准**：

- 录入一个资产条目 < 30s
- 单家庭支持 ≥ 50 个资产条目
- 支持 5+ 种主流货币

### 4.2 资产变化追踪

**用户故事**：作为投资家庭，我想要看到今年总资产涨了多少、哪些资产贡献最大。

**核心图表**：

1. **总资产曲线**：折线图，可切换日 / 周 / 月 / 年
2. **分类占比**：环形图 / 饼图，实时展示各类资产占比
3. **增减变化**：本期 vs 上期、同比、环比
4. **贡献度排行**：本期增长贡献 Top 5 资产
5. **里程碑提醒**：资产达到新高位 / 触发阈值提醒

**关键指标计算**：

| 指标         | 计算公式                      | 用途   |
| ---------- | ------------------------- | ---- |
| **总资产**    | Σ 所有正向资产                  | 全景视图 |
| **净资产**    | 总资产 - 总负债                 | 真实家底 |
| **月度变化**   | 本月末 - 上月末                 | 短期追踪 |
| **同比**     | (本期 - 去年同期) / 去年同期 × 100% | 长期对比 |
| **资产配置比例** | 某类资产 / 总资产 × 100%         | 配置分析 |

### 4.3 数据采集（OCR）

**用户故事**：作为用户，我不想手动输入每个资产，希望截图就能自动识别。

**功能规格**：

- 支持银行 / 券商 App 截图
- OCR 引擎识别关键数字（总金额、净值、市值）
- 用户确认后自动填入
- 支持 10+ 主流银行 / 券商界面
- 不上传原图（本地识别，保护隐私）

**验收标准**：

- 主流银行 / 券商界面识别准确率 > 90%
- 单次识别 < 5s
- 完全离线可用

### 4.4 多人协作

**权限矩阵**：

| 操作   | 管理员 | 编辑者   | 查看者 |
| ---- | --- | ----- | --- |
| 查看资产 | ✅   | ✅     | ✅   |
| 录入资产 | ✅   | ✅     | ❌   |
| 修改资产 | ✅   | 仅本人录入 | ❌   |
| 删除资产 | ✅   | 仅本人录入 | ❌   |
| 邀请成员 | ✅   | ❌     | ❌   |
| 设置预算 | ✅   | ❌     | ❌   |
| 导出数据 | ✅   | ❌     | ❌   |

- 新用户引导：< 3 分钟完成首次资产录入
- 错误提示：所有错误都有清晰文案与解决建议

- MVP 阶段：简体中文（默认）、繁体中文、英文
- 货币：CNY、USD、EUR、JPY 等多币种支持
- 时区：自动识别

## 六、技术栈推荐

| 层          | 推荐方案                                           | 理由                      |
| ---------- | ---------------------------------------------- | ----------------------- |
| **移动端**    | React Native + Expo                            | 上手快、AI 工具链成熟、双端覆盖       |
| **OCR 引擎** | Apple Vision（iOS）/ ML Kit + Tesseract（Android） | 本地识别、隐私安全               |
| **后端**     | Supabase（BaaS）                                 | 内置认证、PostgreSQL、实时同步、降本 |
| **数据库**    | PostgreSQL                                     | 关系型、RLS 数据隔离            |
| **认证**     | Supabase Auth                                  | 支持手机号、邮箱、OAuth          |
| **AI 能力**  | Claude / GPT API + 本地规则引擎                      | 智能洞察、配置建议               |
| **图表库**    | react-native-svg-charts / Victory              | 移动端原生图表                 |
| **部署**     | Vercel / Cloudflare                            | 边缘部署、低成本                |
| **鸿蒙适配**   | ArkTS（鸿蒙原生包）+ RN-HarmonyOS（业务代码复用） | HarmonyOS NEXT 不兼容 Android APK，需独立适配；共享核心逻辑层，UI 层各自实现 |

### 6.2 架构原则

- **本地优先**：所有读写在本地完成，云端异步同步
- **端到端加密**：服务端只看到密文，连管理员也无法解密
- **多家庭隔离**：Row-Level Security 确保家庭间数据绝对隔离
- **可降级**：核心功能在无网络 / 服务故障时仍可用

## 九、竞品分析

| 产品             | 定位        | 优势      | 劣势        | 我们的差异化        |
| -------------- | --------- | ------- | --------- | ------------- |
| **MoneyWiz**   | 个人记账 + 投资 | 跨平台、功能全 | UI 复杂、价格高 | 家庭视角 + 更轻量    |
| **随手记**        | 国内记账      | 用户基数大   | UI 传统、广告多 | 无广告 + 极简 + AI |
| **有鱼记账**       | 记账 + 简单投资 | 自动同步    | 仅手动录入     | OCR + AI 洞察   |
| **且慢**         | 投资记账      | 投资视角    | 单人为主      | 家庭视角 + 全资产类型  |
| **京东金融 / 支付宝** | 综合金融      | 数据真实    | 不专注家庭场景   | 独立第三方 + 隐私至上  |
| **华为钱包 / 鸿蒙生态** | 鸿蒙系统级     | 系统集成度高  | 仅华为系产品    | 跨厂商覆盖 + 家庭视角 + 独立第三方 |

**差异化定位**：

1. **聚焦资产管理**：不抢记账 App 的市场，只解决"看不清家底"的痛点。
2. **轻量录入**：每周 5 分钟，告别每日记账的负担。
3. **家庭协作**：以家庭为单位组织资产，而非个人资产拼凑。
4. **强隐私**：本地优先 + 端到端加密，连服务端都看不到明文。
