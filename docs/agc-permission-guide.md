# AppGallery Connect (AGC) 权限申请指引

## 更新说明（2026-09-30）

**方案已更新**：Calendar Kit 替代 ReminderAgent（无需 ACL 审批）

- 权限从 `PUBLISH_AGENT_REMINDER`（ACL 受限，需审批 3-7 天）
- 改为 `READ_CALENDAR` + `WRITE_CALENDAR`（user_grant，用户弹窗授权即可）

## 申请目标

| 项目 | 内容 |
|------|------|
| **权限名称** | `ohos.permission.READ_CALENDAR` + `ohos.permission.WRITE_CALENDAR` |
| **权限级别** | user_grant（用户弹窗授权，无需 AGC 审批） |
| **权限用途** | 在系统日历中创建盘点提醒事件 |
| **应用场景** | 月末盘点提醒：每月在系统日历中创建提醒事件，由日历 App 负责到点通知 |
| **所属应用** | 家资 (com.familywealth.app) |

## 权限申请方式

### 方式一：自动弹窗（推荐，无需审批）

应用首次使用提醒功能时，系统自动弹出权限申请对话框：

1. 用户打开「我的 → 盘点提醒」
2. 开启开关时触发 `requestCalendarPermission()`
3. 系统弹窗：「家资想要访问您的日历」
4. 用户点击「允许」→ 立即生效

### 方式二：AGC 能力声明（可选，用于上架审核说明）

如上架审核时要求说明日历权限用途：

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)
2. 进入 **我的应用** → 选择 **家资**
3. 左侧导航：**开发 > 能力接入 > 权限管理**
4. 填写权限用途说明（见下方模板）

## 权限用途说明模板

```
【权限名称】READ_CALENDAR / WRITE_CALENDAR
【权限用途】在系统日历中创建盘点提醒事件
【使用场景】
  1. 用户在应用内开启"月末盘点提醒"后，应用在系统日历中创建提醒事件
  2. 事件包含：标题"家资盘点 · [月份]"、描述"打开家资 App，更新各账户余额"
  3. 到点时间由系统日历 App 负责提醒，App 被杀也能收到通知
  4. 用户可在系统日历中查看、修改或删除该事件
【用户控制】
  - 提醒功能默认关闭，需用户手动开启
  - 用户可随时在应用内关闭提醒
  - 用户也可在系统日历中删除事件
  - 应用启动时会校验：用户删除的事件会自动重建（如仍在计划内）
【频率】每月 1 次主提醒 + 未完成时最多 3 次重试
【隐私合规】
  - 提醒事件仅存储在本地系统日历，不上传至服务器
  - 不包含任何敏感个人信息
  - 用户授权后可随时在系统设置中撤销
```

## 常见问题

### Q: 用户拒绝日历权限怎么办？

A: 
- 应用内显示权限被拒提示，引导用户去系统设置开启
- 设置页显示「权限未开启，提醒无法送达」红色提示条
- 用户点击提示条可跳转系统设置（当前版本通过文字引导，后续可通过 wantAgent 拉起）

### Q: 用户手动删除了日历事件，还会提醒吗？

A: 
- 应用启动/回前台时会自动校验（diff 机制）
- 发现缺失的事件会在 3 秒内自动重建
- 用户删除后下次打开应用即可恢复

### Q: 多个设备登录同一个账号怎么办？

A:
- 每个设备独立管理各自的日历事件
- 不会互相干扰
- 同步只同步资产数据，不同步日历事件

### Q: 卸载应用后日历事件还在吗？

A:
- 日历事件会保留在系统日历中
- 用户可手动删除
- 重新安装应用后，登录会重新生成事件（基于最新设置）
