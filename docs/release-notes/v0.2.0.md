## 新增功能

### P0-1 月末盘点提醒

每月自动提醒盘点，解决快照模型低频导致的「数据断档」留存隐患。

- 首次进入 App 引导（可跳过）设置盘点提醒日（默认每月最后一日 20:00）
- 当月所有「计入统计」的资产均已更新当月快照后，视为盘点完成，不再提醒
- 未完成则按设定频率（默认每 3 日）重复提醒，最晚追到次月 10 日
- 点击通知直达录入页（Android）/ 录入入口（鸿蒙）
- 支持按家庭维度判断盘点完成度（私有资产按可见性纳入范围）
- 设置页可修改提醒日 / 时间 / 频率或关闭

### 鸿蒙原生 ReminderAgent TurboModule（P0-1 鸿蒙实现）

- 系统级提醒发布：Calendar Kit（`calendarManager`）写入系统日历事件，
  含月度重复规则（日历已可见「家资盘点」事件，App 被杀日历 App 仍负责到点通知）
- 权限：`READ_CALENDAR` + `WRITE_CALENDAR`（user_grant，首次开启时系统弹窗授权），
  无需 ACL、无需 AGC 审批（ReminderAgent 方案已废弃）
- ArkTS 侧 `ReminderAgentTurboModule.ets` + C++ 侧 `ReminderAgentPackage.h`，
  `Index.ets` 与 `PackageProvider.cpp` 双侧注册
