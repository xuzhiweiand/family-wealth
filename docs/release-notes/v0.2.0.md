## 新增功能

### P0-1 月末盘点提醒

每月自动提醒盘点，解决快照模型低频导致的「数据断档」留存隐患。

- 首次进入 App 引导（可跳过）设置盘点提醒日（默认每月最后一日 20:00）
- 当月所有「计入统计」的资产均已更新当月快照后，视为盘点完成，不再提醒
- 未完成则按设定频率（默认每 3 日）重复提醒，最晚追到次月 10 日
- 点击通知直达录入页（Android）/ 录入入口（鸿蒙）
- 支持按家庭维度判断盘点完成度（私有资产按可见性纳入范围）
- 设置页可修改提醒日 / 时间 / 频率或关闭
- 鸿蒙实现：Calendar Kit 写入系统日历事件（`calendarManager`），含月度重复规则，App 被杀日历 App 仍负责到点通知；权限 `READ_CALENDAR` + `WRITE_CALENDAR`（user_grant），无需 ACL、无需 AGC 审批

### P0-2 本地加密备份与恢复

用户最高敏感数据可自主保管，卸载重装无损迁移。

- 一键生成加密备份包（资产、快照、家庭元数据），AES-GCM 加密，密钥体系与现有 E2E 一致
- 保存到本机用户目录并可系统分享，文件名含版本与生成时间（可读）
- 恢复流程：校验 → 解密 → 合并/覆盖预览（展示将新增/修改/覆盖的条目数量）→ 用户确认 → 执行
- 损坏文件 / 错密钥给出友好错误，不产生半写入状态

### P0-3 全平台导出修复

去除 Expo 依赖，鸿蒙端导出恢复可用。

- `file-export.ts` 统一导出通道：Android 系统分享 / 鸿蒙 DocumentViewPicker
- 支持 **CSV（数据明细）** 与 **HTML 报表（P0-5）** 两种格式
- 导出内容遵循可见性（私有资产不出现在家庭视角导出）
- 系统分享取消不报错、不产生重复文件
- 空数据时导出按钮置灰并提示

### P0-4 资产分组

账户增多后的管理刚需。

- 自定义分组（如「银行」「投资」「负债」），资产可移动归属
- 列表按分组折叠/展开，组内小计（资产合计、负债合计）
- 分组排序（上移/下移）、重命名、删除（删除后资产回到「未分组」）
- 组内小计金额与该组资产实际口径一致

### P0-5 月度 / 年度资产报表

台账产品的专业感来源，可分享给家人。

- **月报**：三卡（净资产/总资产/总负债，复用 `buildMonthTotals` 口径与主页一致）、环比变化、当月配置分布、本月快照明细
- **年报**：年初年末对比、月分桶趋势、配置变化、年度大事记（增删资产 + 金额变化 Top 3）
- 数据不足的月份/指标全部 null 占位，不显示错误数字
- `scopeSnapshots` 收敛可见性口径（某月快照全属于被过滤资产时整月视为无数据）
- 支持自包含内联 CSS HTML 导出（离线可打开、排版完整），对接 P0-3 统一通道
- 期间切换：可选范围 = `availableMonths` / `availableYears`（口径内快照去重升序）
