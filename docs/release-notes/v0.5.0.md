## 一、应用市场「版本更新说明」（可直接粘贴）

### 精简版（约 180 字）

> 本次更新新增华为账号登录：在登录页底部一键授权即可进入，首次登录设置一次加密主密码，
> 之后在同一设备再次登录无需重复输入。老用户可在过渡页绑定已有邮箱账号，继续使用原有家庭数据；
> 「我的 → 账号」新增注销账号，注销后可重新绑定其他账号。另新增「帮助与反馈」：
> 内置常见问题解答，可提交问题并生成工单，反馈会直接送达开发者邮箱。

### 完整版（约 360 字）

> **一、华为账号登录**
> 登录页底部新增华为账号登录入口，授权后自动完成身份校验；首次登录引导设置一次加密主密码，
> 资产仍由本机密钥加密，服务端不保存明文。同一设备再次使用华为账号登录时，无需重复输入加密主密码。
>
> **二、绑定已有邮箱账号**
> 老用户可在华为登录过渡页选择「绑定已有邮箱账号」，输入原邮箱与密码完成绑定，
> 继续使用原有家庭数据，无需重新建账。已绑定的账号也可在「我的 → 账号」查看。
>
> **三、注销账号**
> 「我的 → 账号」新增注销账号入口，二次确认后删除云端账号及其华为绑定关系，
> 便于重新绑定其他邮箱账号继续使用。
>
> **四、帮助与反馈**
> 新增常见问题解答；可提交问题类型、描述与联系方式并生成工单号，反馈直接送达开发者邮箱，
> 本机同时保留提交记录，便于跟进。

## 二、0.3.1 → 0.5.0 变更全量清单

### 1. 华为账号登录（v0.5.0）

| 能力 | 说明 |
|---|---|
| 授权登录 | 接入华为 Account Kit 授权登录（非一键登录）；客户端仅持有授权码，App Secret 只存于服务端 Edge Function |
| 首次登录 | 引导设置一次加密主密码，派生 UMK 并写入加密档案（salt + 密码校验信封） |
| 再次登录 | 同设备复用本地 UMK，校验 salt 与信封通过后直接进入首页，免输加密主密码 |
| 绑定老账号 | 过渡页「绑定已有邮箱账号」：校验原邮箱密码后把华为 openID 绑定到该账号，并签发会话 |
| 注销账号 | 「我的 → 账号 → 注销账号」：删除云端账号与 openID 绑定，注销后可重新绑定其他邮箱账号 |
| 登录页规范 | 华为登录按钮置于页面底部、移除花瓣图标，采用官方红胶囊样式；手机号自动授权能力已移除（个人开发者无 phone scope） |
| 隐私合规 | 未勾选隐私政策时点击华为登录，弹窗确认后自动勾选并继续 |

### 2. 帮助与反馈（v0.5.0）

- 本地静态常见问题（换机、口径、账号、提醒）
- 反馈类型 + 500 字描述 + 联系方式，生成工单号 `FB-YYYYMMDD-NNNN`
- 「我的反馈」本机记录与处理状态，提交失败时仅本地保存并给出提示
- 服务端 Edge Function `submit-feedback` 通过 SMTP 发送工单邮件至开发者邮箱
- 邮件主题按 RFC 2047 编码，避免中文主题乱码；SMTP 使用独立的 `FEEDBACK_SMTP_*` 变量，不覆盖 GoTrue 全局配置

### 3. 账号与安全设置

- 「我的」新增「账号」分组：手机号绑定/更换（短信验证码）、注销账号
- 手机号脱敏展示（前 3 后 4 位），绑定结果写入本机 Keychain
- 退出登录保留本地 salt 与 UMK；注销账号后一并清除

### 4. 工程与服务端

- 新增 Edge Function：`huawei-auth`（login / bind / delete-account）、`submit-feedback`
- 新增数据库迁移 `20261104000000_huawei_auth.sql`（`profiles_huawei`）
- `deploy/server/upgrade-huawei-auth.sh` 与 `docker-compose.override.yml`：注入华为凭据与反馈邮件变量
- 鸿蒙新增 HuaweiAccount TurboModule（ArkTS + C++ 双侧注册）与 `module.json5` client_id 配置
- 版本号 5 处同步 0.5.0（mobile package.json、Android build.gradle、鸿蒙 AppScope、MeScreen、HarmonyConfig）

## 四、上架注意事项

1. 隐私政策公网链接需保持可访问（`docs/privacy-policy.md` 已更新至 main 分支）
2. 华为账号登录需保证 AGC Client ID 与 `module.json5` 的 `client_id` 一致，
   服务端 `HUAWEI_CLIENT_ID` / `HUAWEI_CLIENT_SECRET` 已配置（`deploy/server/upgrade-huawei-auth.sh`）
3. 「注销账号」入口位于「我的 → 账号」，审核时可直接验证账号删除链路
4. 手机号绑定依赖 Supabase Phone OTP 短信通道；若提审环境未配置短信服务商，
   建议暂时隐藏「我的 → 账号 → 手机号」入口
5. 反馈邮件依赖 Edge Function `submit-feedback` 与 SMTP 配置，提交失败时会提示「已保存到本机」
6. 截图需覆盖：登录页（底部华为入口）、华为首次登录设置加密密码页、
   我的账号页（绑定/注销）、帮助与反馈页、更新数据页、趋势页
7. Android release APK 需另行构建，versionCode 13 / versionName 0.5.0
