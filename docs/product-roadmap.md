## 1. 产品概述

### 1.1 背景

家庭资产分散在现金、银行存款、理财、股票基金、房产车辆、贷款等多个账户中，
家庭成员（夫妻、父母子女）之间又普遍存在「账目不透明、口径不一致」的问题。
市场上的主流产品分为两类：

1. **流水记账派**（钱迹、随手记、Monarch）：逐笔记收支，功能重、坚持成本高，
   且均为云端明文（或仅传输加密），家庭财务这一最高敏感等级的数据需要交给服务商；
2. **净值台账派**（Know Your Dosh、Empower）：以账户余额快照看全貌，
   但国内市场基本空白，且缺乏家庭协同能力。

### 1.2 愿景与定位

> **让一家人安心地看清家底。**

家资是一款**家庭资产月度台账**工具：每月给账户记一笔余额，自动生成
家庭净资产、总资产、总负债的全貌与趋势；通过家庭共享实现协同，
通过端到端加密实现「数据只属于用户自己」。

差异化三角（不偏离的产品原则）：

- **轻**：月度快照，不逐笔，3 分钟完成一次盘点；
- **暖**：为家庭设计，你的/我的/全家，可见性可控；
- **安全**：端到端零知识加密，服务端永远看不到明文。

### 1.3 目标用户

| 画像              | 特征                   | 核心诉求              |
| --------------- | -------------------- | ----------------- |
| 新婚/已婚家庭财务管理者（主） | 25–45 岁，家庭资产账户 5 个以上 | 家庭净资产全貌、夫妻透明、数据私密 |
| 有负债的中产家庭        | 房贷/车贷/信用卡，关注偿债进度     | 负债管理、净资产趋势、目标感    |
| 多代家庭协作者         | 子女帮父母管理资产            | 细粒度权限、操作简单        |

### 1.4 核心场景

1. 月末收到提醒 → 打开家资 → 对照银行 App 更新各账户余额 → 查看本月家底变化；
2. 邀请配偶加入家庭 → 各自记录私有账户、共同记录家庭资产 → 切换「全家」视角看净资产；
3. 年初查看年度报表 → 对比年初年末、了解资产配置分布 → 设定新年净资产目标；
4. 更换手机 → 导出/恢复加密备份 → 数据无损迁移。

### 2.2 北极星与关键指标

- **北极星指标**：每月完成至少一次盘点的家庭数（月度活跃盘点家庭 MAHF）。

| 漏斗/维度 | 指标            | 定义                   |
| ----- | ------------- | -------------------- |
| 获取    | 注册转化率         | 落地 → 完成注册            |
| 激活    | 首笔快照完成率       | 注册后 24h 内录入 ≥1 个资产快照 |
| 留存    | 次月盘点完成率       | 首月用户在次月仍完成盘点的比例      |
| 家庭    | 家庭创建率 / 邀请接受率 | 创建家庭并成功加入第二名成员       |
| 安全    | 备份开启率         | 启用本地备份或完成过一次导出       |
| 稳定    | 崩溃率 / 同步成功率   | 崩溃会话占比；syncNow 成功比例  |

> 目标值在 v0.2 发布后基于基线数据设定；先埋点、后定标。

## 3. 竞品依据（摘要）

| 能力            | 家资       | 钱迹     | 随手记     | Monarch   | Know Your Dosh |
| ------------- | -------- | ------ | ------- | --------- | -------------- |
| 记账模型          | 月度快照     | 流水     | 流水      | 流水+银行同步   | 净值快照           |
| 家庭共享          | ✅ 角色+可见性 | ✅ 共享账本 | ✅ 多人    | ✅ 伴侣+视角切换 | ✅ 权限式          |
| 端到端零知识加密      | **✅**    | ❌      | ❌       | ❌         | ❌              |
| 预算 / 负债 / 多币种 | ❌        | ✅      | ✅       | 预算✅       | ❌              |
| 自动记账          | ❌        | ✅ 强    | ✅       | ✅ 强       | ❌              |
| 平台数           | 2        | 9      | App/Web | 3         | 多              |
| 价格            | 免费       | VIP 订阅 | 免费+金融变现 | $99.99/年  | £4.99/月        |

**结论**：国内「家庭净值台账 + 零知识加密」生态位空白；
Monarch 2025-10 的 Shared Views 与 Know Your Dosh 验证了家庭/权限方向；
应加固差异化，不补全为「又一个流水记账 App」。

## 4. 需求清单

优先级定义：**P0** = 下一版本必须交付；**P1** = 随后两个版本内；**P2** = 按资源与数据排入。
估算为 T 恤尺码（S ≤3 人日，M 3–8 人日，L 8–15 人日，XL >15 人日）。

### 4.1 P0 — v0.2「记得住、丢不了」

---

#### P0-1 月末盘点提醒

- **背景**：快照模型低频，用户忘记盘点即数据断档，是留存第一隐患。
- **功能描述**：
  - 本地通知，用户可设置提醒日（默认每月 1 日或最后一日）与时间；
  - 当月所有「计入统计」的资产均已更新当月快照后，视为盘点完成，不再提醒；
  - 未完成则按设定频率（如每 3 日）重复提醒；点击通知直达录入页；
  - 支持按家庭维度判断完成度。
- **验收标准**：
  1. 首次进入 App 引导（可跳过）设置盘点提醒；
  2. 到达提醒时间且当月未盘点 → 收到本地通知，点击进入录入页；
  3. 当月全部资产已有快照 → 不再收到提醒；
  4. 可在设置中修改提醒日/时间/频率或关闭；
  5. Android 与鸿蒙双端行为一致，无后台时通知仍可达。
- **估算**：M

---

#### P0-2 本地加密备份与恢复

- **背景**：当前「本地备份」为 stub；用户最高敏感数据需要可自主保管。
- **功能描述**：
  - 一键生成**加密备份包**（资产、快照、家庭元数据，密钥体系与现有 E2E 一致），
    保存到本机用户目录并可系统分享；
  - 支持从备份包恢复（校验 → 解密 → 合并/覆盖预览 → 执行）；
  - 备份包含版本与生成时间，文件名可读。
- **验收标准**：
  1. 生成的备份包在设备文件系统可见，可分享/拷贝；
  2. 备份包离开用户密钥无法解密（抽查：篡改/错密钥 → 明确报错）；
  3. 卸载重装后从备份恢复，资产、快照、可见性、家庭关系完整；
  4. 恢复前展示将新增/修改/覆盖的条目数量，用户确认后执行；
  5. 损坏文件给出友好错误，不产生半写入状态。
- **估算**：L

---

#### P0-3 全平台导出修复

- **背景**：去 Expo 后鸿蒙端导出不可用、入口被隐藏，属于功能缺口。
- **功能描述**：
  - 去除 Expo 依赖，鸿蒙使用文件系统 + 系统分享；
  - 支持 **CSV（数据明细）** 与 **HTML 月报（见 P0-5）** 两种导出；
  - 无系统分享能力时保存文件并告知路径。
- **验收标准**：
  1. Android/鸿蒙均可导出 CSV，中文与金额格式正确，可用表格软件打开；
  2. 导出内容遵循可见性（私有资产不出现在家庭视角导出）；
  3. 系统分享取消不报错、不产生重复文件；
  4. 空数据时导出按钮置灰并提示。
- **估算**：M

---

#### P0-4 资产分组

- **背景**：钱迹 2025-09 上线资产分组，账户增多后管理刚需。
- **功能描述**：
  - 自定义分组（如「银行」「投资」「负债」），资产可移动归属；
  - 列表按分组折叠/展开，组内小计（资产合计、负债合计）；
  - 分组排序、重命名、删除（删除后资产回到「未分组」）。
- **验收标准**：
  1. 可新建/重命名/删除/排序分组，资产可在分组间移动；
  2. 折叠状态与分组配置跨设备同步（或明确为本机配置）；
  3. 组内小计金额与该组资产实际口径一致；
  4. 删除分组不删除任何资产。
- **估算**：M

---

#### P0-5 月度 / 年度资产报表

- **背景**：台账产品的专业感来源；可分享给家人，自带传播与家庭场景。
- **功能描述**：
  - 月报：三卡（净资产/总资产/总负债）、环比变化、配置分布、本月快照明细；
  - 年报：年初年末对比、12 月趋势、配置变化、年度大事记；
  - 支持 HTML 导出与系统分享（对接 P0-3）。
- **验收标准**：
  1. 月报数字口径与主页、月度台账完全一致；
  2. 数据不足的月份/指标有占位说明，不显示错误数字；
  3. 导出的 HTML 离线可打开、排版完整；
  4. 报表遵循可见性口径。
- **估算**：L

## 5. 路线图与里程碑

```text
2026 Q4  v0.2  记得住、丢不了
          ▸ M1 需求评审/设计完成
          ▸ M2 盘点提醒 + 导出修复（可先发灰度）
          ▸ M3 备份恢复 + 分组 + 月报，双端回归发布

2027 Q1  v0.3  一家人算一本账
          ▸ M1 家庭管理 + 视角切换
          ▸ M2 负债还款计划（最复杂，单独立项）
          ▸ M3 目标 + 轻量流水，发布

2027 Q2  v0.4  看得懂
          ▸ AI 简报 + 年报；多币种按用户数据决定是否提前

2027 Q3  v0.5  用得爽
          ▸ CSV 导入 + 小组件 + 深色 + 鸿蒙 OCR

2027 H2  v1.0  信任闭环
          ▸ 双端稳定指标达标、合规齐备；评估订阅/买断与 iOS
```

里程碑通用准出条件：双端真机回归通过 → 关键埋点验证 → 灰度无新增崩溃 →
文档（含 ADR/runbook）更新 → 版本号 5 处同步。

## 6. 非目标（明确不做）

| 不做事项 | 原因 |
|---|---|
| 无障碍自动记账 / 银行数据同步 | 合规与维护成本高，与快照定位冲突 |
| 理财超市、信贷、保险导流 | 摧毁「零知识、只属于你」的信任根基 |
| 完整消费分类与预算体系 | 流水战场正面竞争无优势（预算仅在有明确数据后再评估） |
| Mac/Windows/Watch 全平台铺开 | 9 平台是规模化团队的结果，当前资源不支撑 |
| 自行采集/售卖用户数据 | 与产品存在理由相悖 |

## 7. 风险与依赖

| 风险/依赖 | 影响 | 应对 |
|---|---|---|
| 鸿蒙原生能力不全（通知/文件/分享/OCR） | P0 多项受阻 | 提前做技术 Spike；能力缺失按最小可见方案兜底，不留死入口 |
| 快照低频导致留存天然偏低 | 北极星指标压力 | 盘点提醒 + 月报 + 轻量变动逐步提升打开理由 |
| 单人/小团队资源 | 路线图延期 | 每版本严格限范围；P1/P2 按数据动态排序，不承诺日期 |
| APP 备案等合规未完成 | 上架受阻 | 备案作为 v0.2 发布前置，专人推进 |
| 加密体系改动风险 | 数据不可恢复 | 备份先行；任何密钥/加密变更必须有 ADR 与迁移方案 |

## 8. 度量与复盘机制

1. **埋点先行**：v0.2 起覆盖注册、首笔快照、盘点完成、备份、导出、家庭邀请漏斗；
2. **版本复盘**：每版本发布后 2 周回顾指标与崩溃，更新本文档状态；
3. **季度规划**：依据指标与用户反馈重排 P1/P2，路线图日期不视为承诺；
4. **用户反馈闭环**：帮助与反馈入口（当前为邮箱）在 v0.2 接入结构化反馈。
